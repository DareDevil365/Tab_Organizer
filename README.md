# Tab Organizer

This is the original Chromium extension and FastAPI backend from the project backup.

Build the extension in `Tab_Organizers/extension` with `npm ci` and `npm run build`, then load `Tab_Organizers/extension/dist` as an unpacked extension. Start the local backend from `Tab_Organizers/backend` after installing `requirements.txt`. Run `python -m app.main` to start FastAPI on port 8742.
